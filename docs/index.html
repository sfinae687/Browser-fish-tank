一个标签页 = 一只发光生物

这不是一个屏保，也不是一个装饰。它同时是一个 可视化的标签页管理器 —— 你不需要去数标签栏，看一眼水里就知道自己开了多少、哪些在吵、哪些可以关。

休眠 / 已丢弃 暗淡蛰伏，几乎不动 —— 一眼看出哪些可以关掉
正在出声 辉光脉动，明显更亮 —— 比找那个小喇叭图标直观
已固定 体型更大、活动范围更窄，有领地感

四种气氛

都在「近黑水体 + 冷光 + 发光生物」这个框架内，只换气氛不换风格。

五种远景

水体本身只有一个渐变，看久了会显得空。远景给画面一个纵深参照物 —— 换一个就换一种气氛。

六种生物

形状是设计出来的，不是随机采样出来的 —— 参数在区间里随机组合的结果，是每一只的比例都「差一点」， 而且放在一起互相打架。

装上它

一个 Chromium MV3 扩展，新标签页与页面覆盖层两个表面各自独立配置。 不联网、不收集任何数据。

  1. 克隆仓库，pnpm install && pnpm build
  2. 打开 chrome://extensions，开启开发者模式
  3. 「加载已解压的扩展程序」选择 dist/ 目录
  4. 打开一个新标签页
在 GitHub 上查看

覆盖层需要在设置页里主动启用并授予 <all_urls> 权限 —— 「读取标签页标题」也是可选的，不授权时生物照常可见可点，只是没有标题。
